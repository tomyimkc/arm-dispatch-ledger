# model_id : short slug ([a-z0-9._-]+), used as a cache-key component and as

# hf_repo  : "<org>/<repo>" on huggingface.co.
# hf_file  : exact filename inside that repo, fetched from
#            https://huggingface.co/<hf_repo>/resolve/main/<hf_file>.
# sha256   : sha256 of the exact bytes at that URL, captured by a REAL
#            download + `shasum -a 256` (not derived from the HF
#            X-Linked-ETag response header sight-unseen — that header comes
#            from HF's Xet/CAS storage layer and is a content hash, which
#            happened to also equal the sha256 for every file below when
#            cross-checked on 2026-08-04, but that is a lucky coincidence of
#            this storage backend, not a documented guarantee, so the
#            authoritative value here always comes from a real download).
# license  : verified LIVE against the HF API's cardData.license field —
#            `curl -s https://huggingface.co/api/models/<hf_repo> | \
#              python3 -c "import json,sys;print(json.load(sys.stdin)['cardData']['license'])"`
#            — never copied from a README by eye. Only apache-2.0 or mit
#            entries may be added: this repo is Apache-2.0 and its Devpost
#            submission publishes fetch instructions that must not point a
#            reader at a non-commercial license.
# notes    : why this model is in the set / what evidence gap it closes.
